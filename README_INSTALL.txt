BERK'S BOOK — OFFICIAL PAPER TRACKING SAFEGUARD

This update keeps the existing two-model workflow and explicitly starts official paper tracking on November 11, 2026.

Rules:
- V1 and V2 are tracked independently.
- Both teams must have at least 10 qualifying current-season games.
- Each model needs a market edge of at least 5.5 points.
- Picks are recorded only before tipoff and only for games dated November 11, 2026 or later (Eastern Time).
- Earlier preview forecasts and completed games are never added retroactively.
- Each pick keeps the sportsbook line and price from the same book.
- V2's 5.5-point threshold is evaluated using the unrounded model edge.
- Results are graded as wins, losses, or pushes; this is paper tracking only.

Install from iPad:
1. Unzip this package in the Files app.
2. Open your GitHub repository in Safari.
3. Upload the replacement files from this ZIP to the repository root:
   update.py, index.html, README.md, README_INSTALL.txt
4. Commit the changes.
5. Open Actions > Update NBA dashboard > Run workflow.
6. Wait for a green check, then refresh the dashboard.

Keep your existing .github/workflows folder, archive.json, odds_snapshots.json, paper_bets.json, app.js, styles.css, and dashboard.json. Do not upload the ZIP itself.
Do not share your ODDS_API_KEY in chat or place it in any website file.
